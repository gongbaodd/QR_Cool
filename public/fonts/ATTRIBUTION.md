# Bundled text-mask fonts — attribution and licenses

Display fonts used by the editor's "draw the region from a word" mask tool
(`src/lib/editor/text-mask.ts`, `@font-face` in `src/app/globals.css`).
Font binaries are kept under their original downloaded filenames wherever
possible (some licenses forbid renaming); each license/readme shipped with
the download is copied alongside under a prefixed name.

Only **FatC** is marked 100% Free with no strings attached. Everything else
is **personal-use-only, donationware, or requires permission/payment for
commercial use**. Posters assembled with these fonts inherit those terms —
check the row for the font you used before publishing or selling a poster.
